# Ateliê do Sabor

Landing page de pré-inscrição para os cursos Culinária Essencial e Culinária Kids da escola de culinária fictícia Ateliê do Sabor.

## Como rodar

```bash
npm install
npm run dev
```

Abra http://localhost:3000.
